## 기본값 타입

- JPA의 데이터 타입 최상위 레벨

### 1. 엔티티 타입

- @Entity 로 정의하는 객체

- 데이터가 변해도 식별자로 지속해서 추적할 수 있다.

- 내부 데이터가 변해도 그 값의 식별자를 알면 계속 인식할 수 있음(키, 나이 변경해도 그 회원인걸 알 수 있음)

### 2. 값 타입

- int, integer, String 같이 단순 값으로

- 식별자가 없음

- 100을 200으로 바꾸면 원래 뭐였는지, 과거에 뭐였는지 알 수 없음

- 게시판 String 컨텐츠 그 자체가 값타입. 수정하면 원래 뭐였는지 몰라

## 값 타입의 분류 3가지

### 1. 기본값 타입

- 자바 기본 타입
- Wrapper Class
- String

### 2. 임베디드 타입

- 좌표, 우편번호 같이 묶어서 사용하는 값들
- 내가 커스텀 해서 값처럼 쓰고 싶을 때

### 3. 컬렉션 타입

- 컬렉션

## 기본값 타입

- String name, int age

- 생명주기를 엔티티에 의존 : 회원을 삭제하면 이름, 나이 필드도 함께 삭제

- `값 타입은 공유하지 않는다.`

- 회원 이름을 공유하여, A의 이름을 변경했더니 B의 이름도 변경하는 것 처럼

- 자바의 기본 타입은 절대 공유되지 않는다. (int)

- int a=10, b=a 를 하면, b는 a의 값을 복사하여 값을 부여 된다.

- 하지만 Integer 같은 Wrapper 클래스, String 같은 특수 클래스는 값이 공유된다. 하지만 변경할 방법이 없어서 서로 영향 줄 일은 없음

- 참조값이 넘어가는 거
