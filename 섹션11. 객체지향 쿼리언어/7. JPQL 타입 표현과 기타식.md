## JPQL 타입 표현

- 문자 : ''
- 숫자 : 10L, 10D, 10F

- Boolean : TRUE, FASLE

- ENUM : jpabook.MemberType.Admin(패키지명을 포함한 enum)

- 엔티티 타입 : TYPE(m) = Member( 상속관계 볼때 사용)

```java
em.createQuery("select i from Item i where type(i) = Book", Item.class);

//DiscriminatorColumn() 으로 클래스 엔티티이름 지정한 그 이름
```

이런식으로 원하는 Dtype의 item을 가져올 때 사용할 수 있음
