## 페이징 API

- JPA는 페이징을 두 API로 추상화 한다.

- 몇번째 부터 몇개 가져올래?

- setFirstResult(int startPosition) : 조회 시작 위치

- setMaxResults(int maxResult) : 조회할 데이터 수

```java
List<Member> result =  em.createQuery("select m from Member m order by m.age desc")
    .setFirstResult(0)
    .setMaxResult(10)
    .getResultList();
```

- 스프링 JPA 페이징이 쉬워.
