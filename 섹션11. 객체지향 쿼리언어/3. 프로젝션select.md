## Select - Projection

- Select 절에 조회할 대상을 지정하는 것

- 대상 : 엔티티, 임베디드 타입, 스칼라 타입(숫자, 문자)

- SQL처럼 테이블만 조회하는 게 아니다

- Select m from Member m : 엔티티 프로젝션

- Select m.team from Member m : 엔티티 프로젝션

- Select m.address From Member m : 임베디드 타입 프로젝션

- Select m.username, m.ge From Member m : 스칼라 타입 프로젝션

- Distinct로 중복 제거

```java
List<Member> result = em.createQuery("select m from Member m ", Member.class).getResultList();

Member findMember = result.get(0);

findMember.setAge(20);

tx.commit();
//이렇게 하면 업데이트 쿼리까지 날라간다.
//Select 시 엔티티 프로젝션을 하면 영속성이 다 관리 된다.

List<Member> result = em.createQuery("select m.team from Member m ", Member.class).getResultList();

//inner 조인 한 결과를 가져온다.

// team과 Member 조인 : join을 명시적으로 하는게 좋다.




List<Member> result = em.createQuery("select o.address from Order o ", Order.class).getResultList();
//Order 안에 있는 임베디드 타입 address를 잘 가져온다.

List<Member> result = em.createQuery("select distinct m.username, m.age from Member m ").getResultList();
// 스칼라 타입 프로젝션 : 일반 SQL과 같은 것
```

## 프로젝션 여러 값 조회할 때

- TypeQuery를 이용하는 방법

```java
for (Object o : result) 형태로 object, Object[]로 형변환
```

- new 명령어로 조회

- 단순 값을 DTO로 바로 조회

```java
List<Member> result = em.createQuery("select new jpql.MemberDTO(m.username, m.age) from Member m ", MemberDTO.class).getResultList();


public class MemberDTO{

    private int age;

```
